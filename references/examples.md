# Example Prompts

Use these as trigger and output-shape examples for `completion-learn`.

## Default Self-Evolution

`/learn-complete`

Meaning:
- the task is done
- tell me how I get better
- tell me how my tools get better
- tell me how I and the tools work better together

## Plain Debrief

`/learn-complete 这次任务已经做完了，帮我总结最该记住的经验。`

## Skill Sedimentation Check

`/learn-complete 这轮任务结束了。顺便看一下，有没有哪段流程值得沉淀成 skill。`

## Boundary Decision

`请做一个 completion debrief，并判断这次应该扩展现有 skill 还是新建 skill。`

## Minimal Learning Artifact

`任务结束了。给我一个很短的 durable rule，再说这次有没有 skill sedimentation 候选。`

## Recommendation Only

`/learn-complete 只做复盘和 skill 沉淀建议，不要改任何 skill 文件。`

## Debugging Focus

`/learn-complete debugging 这次排查做完了，帮我总结最关键的调试信号、错假设和下次该先跑的 verifier。`

## Workflow Focus

`/learn-complete workflow 这轮任务结束了，帮我看流程哪里最浪费，哪些步骤应该沉淀成默认动作。`

## Collaboration Focus

`/learn-complete collaboration 复盘一下这次和用户/审稿人/队友交互里，哪些表达方式最有效，哪些地方容易误解。`

## Deep Reflection

`/learn-complete deep research-writing 不要只总结结果，重点分析这次判断、论证和证据组织里最该长期保留的东西。`
