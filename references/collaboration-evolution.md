# Collaboration Evolution

Use this note for the second axis of the default `completion-learn` debrief.

This axis is about improving the operating loop between the user and the tool, not about generic teamwork slogans.

## What To Look For

- what communication pattern reduced ambiguity fastest
- what level of visibility gave the user enough global context without overload
- where the division of labor was clean and where it blurred
- what escalation threshold should be used next time

## Core Questions

1. What should become the default interaction pattern?
2. What should be clarified earlier next time?
3. What kind of progress updates are actually useful to the user?
4. Where should ownership stay with the user, and where should the tool act more autonomously?

## Preferred Output

Keep this axis concrete:
- `Default pattern`
- `Clarify earlier`
- `Ownership split`
- `Next collaboration upgrade`

## Priority Rule

This axis comes before tool evolution in the default three-axis mode.
