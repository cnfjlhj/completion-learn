# Focus Lenses

Use one primary lens for each `completion-learn` debrief. Add a second lens only when the task genuinely spans two different learning modes.

## Debugging

Use when the task involved diagnosis, root cause finding, failing tests, flaky systems, or confusing symptoms.

Emphasize:
- what signal actually broke the deadlock
- which assumptions were wrong
- what verifier should be used earlier next time

## Design

Use when the task involved architecture, abstraction boundaries, decomposition, or tradeoff choices.

Emphasize:
- which boundary decisions mattered
- where coupling or hidden complexity came from
- how to choose the simpler stable design next time

## Workflow

Use when the main lesson is about process quality rather than pure code.

Emphasize:
- planning quality
- batching and sequencing
- checkpoints, backups, rollback paths, and operator hygiene

## Collaboration

Use when the learning is about working with the user, another model, reviewers, or teammates.

Emphasize:
- what communication pattern reduced ambiguity
- where ownership became blurry
- how to ask better narrowing questions or give better status updates

## Research-Writing

Use when the task involved papers, rebuttals, literature, citation logic, or research communication.

Emphasize:
- claim-evidence alignment
- framing quality
- what made an argument persuasive or weak

## Tool Use

Use when the main lesson is how tools, scripts, search, or environment evidence should be used.

Emphasize:
- which tool gave decisive leverage
- where tool output was misread or underused
- what exact tool sequence should become standard

## Decision Quality

Use when the most valuable lesson is judgment under uncertainty.

Emphasize:
- what was known vs assumed
- whether the decision was reversible
- which missing evidence should have been gathered sooner

## Choosing Without User Focus

If the user gives no focus:
- choose the lens that explains the biggest mistake or biggest win
- prefer `Debugging`, `Workflow`, or `Decision Quality` over a vague generic recap
- avoid using more than two lenses in one debrief
