# Self Improvement

Use this note for the first axis of the default `completion-learn` debrief.

This axis should help the user regain attention, notice themselves more clearly, and improve their own operating quality before discussing tools.

## What To Look For

- where the user's attention was fragmented, hijacked, or diffused
- where they noticed the right thing at the right time
- where they outsourced too much judgment instead of keeping ownership
- what personal habit would make the next similar task calmer, clearer, or stronger

## Core Questions

1. What should the user keep because it clearly helped?
2. What should the user stop because it repeatedly drains attention or creates drag?
3. What should the user practice next to become stronger, not just more informed?
4. What was the moment where stronger self-noticing would have changed the outcome?

## Preferred Output

Keep this axis concrete:
- `Keep`
- `Stop`
- `Practice next`
- `Durable rule`

## Priority Rule

If the debrief must stay short, this axis gets first claim on attention.
