# Self Improvement

Use this note for the first axis of the default `completion-learn` debrief.

This axis should help the user see what should remain on the human side after the task: attention patterns, phrasing habits, emotional handling, ownership, and judgment quality.

Do not assume the user retained a capability just because the task ended well. Ask what would still hold if one layer of tool support were removed.

## What To Look For

- where the user's attention was fragmented, hijacked, or diffused
- where their wording clarified the task or amplified confusion
- where emotion distorted or improved the interaction
- where they noticed the right thing at the right time
- where they outsourced too much judgment instead of keeping ownership
- what on the human side is worth keeping as durable residue

## Core Questions

1. What from the user's input process should be kept because it clearly helped?
2. What should the user stop because it repeatedly drains attention, worsens phrasing, or creates drag?
3. What should the user practice next to become stronger, not just more informed?
4. What was the moment where stronger self-noticing would have changed the outcome?
5. If the tool were removed tomorrow, which part of the user's judgment would still remain?

## Preferred Output

Keep this axis concrete:
- `Keep`
- `Stop`
- `Practice next` under reduced support or as a nearby transfer move
- `Durable rule`

## Priority Rule

If the debrief must stay short, this axis gets first claim on attention.
