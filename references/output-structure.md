# Output Structure

Use the smallest structure that still preserves the real lesson.

## Light

Use for straightforward tasks or when the user wants a short debrief.

Output:
- `Top lesson`
- `You: Keep`
- `You: Stop`
- `Collaboration: Improve`
- `Tool: Improve`
- `Durable rule`
- `Next drill`
- `Skill sedimentation`

## Standard

Use for most meaningful completed tasks.

Output:
- `Primary lens`
- `What mattered most`
- `Repeatable wins`
- `Mistake patterns`
- `You: Keep`
- `You: Stop`
- `You: Start next time`
- `Collaboration: What should become default`
- `Tool: What should evolve`
- `Tool: Existing skill optimize or second skill`
- `Durable rules`
- `Next deliberate practice`
- `Skill sedimentation`

## Deep

Use when the task was novel, expensive, messy, or strategically important.

Output:
- `Primary lens`
- `Secondary lens` if needed
- `What happened`
- `What actually changed the outcome`
- `Repeatable wins`
- `Mistake patterns`
- `You: Keep`
- `You: Stop`
- `You: Start next time`
- `Collaboration: What should become default`
- `Tool: What should evolve`
- `Tool: Existing skill optimize or second skill`
- `Counterfactual: what would have failed if done the old way`
- `Durable rules`
- `Next deliberate practice`
- `Skill sedimentation`

## Style Rules

- Prefer short, direct sections over essay prose.
- Turn vague feelings into named patterns.
- End with practice and reuse, not just reflection.
- Make the output easy to act on within the next day or next similar task.
- In default mode, make the three axes visible even if the debrief stays short.
- Keep the visible order as `You -> Collaboration -> Tool` unless the user explicitly overrides it.
- Keep `task completion` separate from `capability gain` in your reasoning, even when the visible output stays short.
- `Next deliberate practice` should be a reduced-support drill or a nearby transfer task, not generic encouragement.
- Avoid praise-only summaries.
